# 技術概要 — Quant Research Core

## 目的と設計上の制約

定量リサーチでは、結果が良く見えることよりも、その結果を信頼できる条件が揃っていることを重視しました。特に、未来情報の混入・試行回数の過少申告・取引コストの過小評価を避けることを目標にしています。

## 主要な処理の流れ

```text
研究仮説（人間またはLLMが提案）
        ↓
宣言的な戦略仕様・スキーマ検証
        ↓
時点整合性のあるデータ参照 (PIT)
        ↓
バックテスト（翌バー約定・取引コスト）
        ↓
独立したリーク監査
        ↓
統計検証 / 分割検証
        ↓
結果・設定・ハッシュ・監査記録を登録
        ↓
採用候補の提案（最終判断は人間）
```

## 検証の考え方

### 時点整合性

元データの時刻を一つにまとめず、イベント発生時刻・公開/利用可能時刻・取得時刻を区別します。戦略が参照できるのは、判定時点で利用可能だったデータだけです。

### Holdoutの分離

学習・候補選別・検証・最終確認を分け、繰り返し参照による情報漏洩を検出する仕組みを設計しました。

### 実行条件とコスト

約定の遅延や手数料、スプレッド、スリッページを明示し、楽観的な前提が収益性を過大評価しないようにします。

### LLMの扱い

LLMは仮説候補の生成やレビューに使用します。ただし、生成内容を正解として受け入れず、構造化出力・監査・テスト・人間による判断の境界を設けています。

### 再現性

実験ごとの戦略仕様、データ識別子とハッシュ、乱数シード、コード版、結果、監査所見などを記録する構成です。

## デモとの関係

[`examples/pit_demo.py`](../examples/pit_demo.py) は「今の時点ではまだ公開されていないデータを参照できない」という一つの原則だけを可視化した、小規模な独立実装です。研究システム本体の性能・収益性・完全性を証明するものではありません。

## 公開範囲

研究用システム本体は非公開です。プロバイダー由来の市場データや外部APIの認証情報は公開しません。この文書は個人開発の設計説明であり、顧客納品実績ではありません。

## ミニ研究パイプライン（合成データ・実行デモ）

```text
人が記述した仮説 (JSON)      # LLMの実APIは使わない
       ↓
仕様・データ検証             # 不正値や分割条件を拒否
       ↓
PIT参照                     # その時点で利用できる終値だけを参照
       ↓
シンプルな売買シミュレーション # 前日引けの判断 → 次のバーの寄り付きで模擬約定
       ↓
アクセスログ・約定条件の検査 # 記録された未来参照や不正な約定日付をチェック
       ↓
Train/Test/Holdout集計       # 記述統計のみ。学習や有意性検定は未実装
       ↓
JSONレポート保存             # 入力ファイルSHA256を含む
       ↓
REVIEW_REQUIRED / REJECTED   # 自動承認しない
```

実行：

```bash
python examples/research_pipeline_demo.py
python examples/research_pipeline_demo.py --inject-leak --out artifacts/leak-report.json
python -m unittest discover -s tests -v
```

1行目は正常ケースで `REVIEW_REQUIRED`、2行目は未来データ参照を意図的に混入させ、監査で `REJECTED`（終了コード2）になる。実験記録は `artifacts/` に書き出される（Git追跡対象外）。

**取引費用の計上:** 買付時は `shares = cash / (open * (1 + rate))` とすることで購入額と手数料の合計が元の現金を超えないようにしています。売却時は受取額から手数料を控除します。これは固定比率による簡易モデルであり、実市場のスプレッド・流動性・約定ずれを推定するものではありません。

**監査の限界:** ログに記録された参照・約定の日時や価格を元データと照合します。未記録の参照、ログ欠損、戦略計算の再演算、改ざん耐性は保証せず、完全な独立監査として扱いません。デモのTrain/Test/Holdoutは分割区間の収益率集計であり、独立した戦略探索・最適化の検証ではありません。

**このデモの範囲:** 14本の架空の日足、単一銘柄、移動平均によるロング／現金のみの戦略、単純な片道取引費用、Train/Test/Holdoutでの区間収益率。研究システム本体の実装を再現したものではなく、機能検証の考え方を説明する独立教材である。適応的なモデル学習、実データの厳密なPIT管理、コーポレートアクション、複数仮説の多重検定、統計的有意性、ブローカー連携は含まない。
